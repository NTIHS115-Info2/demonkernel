## Summary
- 將 system-prompt-manager 的 default fallback 改為可由檔案提供，且 prompt 內容不提交

## Changes
### Added
- 新增 `assets/prompts/default.system.prompt.md` 作為 fallback prompt 檔案路徑；實際內容檔由本機或部署環境提供
- 新增 default prompt 檔案 fallback 與熱讀取測試

### Changed
- requested state 找不到對應 prompt 檔時，改為讀取 `default.system.prompt.md`
- state 缺失時也改為讀取 `default.system.prompt.md`
- 將 `system-prompt-manager` 升級為 `0.1.2`，TalkEngine exact dependency 更新為 `system-prompt-manager@0.1.2`

### Fixed
- 修正 default prompt 只能透過 code 常數修改的問題

### Removed
- 移除 default prompt 作為主要 fallback 的 hard-coded 行為；僅保留 default 檔案也不可用時的 emergency fallback

## Impact
- 維護者可透過本機或部署環境提供的檔案修改 default prompt，方式與一般 state prompt 一致
- 若指定 state 檔案不存在，runtime 仍可回到可控的 default prompt 檔案
