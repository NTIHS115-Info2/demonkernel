## Summary
- 修正 system-prompt-manager 的 state 處理，移除 hard-coded `common` 限制

## Changes
### Added
- 新增任意上游 state 對應 prompt 檔案的測試覆蓋

### Changed
- `system-prompt-manager` 改為依呼叫端傳入 state 尋找 `{state}.system.prompt.md`
- 找不到對應 prompt 檔、state 缺失或讀取失敗時，維持 `logger.warn` 並回傳 fallback prompt
- 將 `system-prompt-manager` README 改為中文說明，並補上 state 由上游傳入的責任邊界
- 將 `system-prompt-manager` 升級為 `0.1.1`，TalkEngine exact dependency 更新為 `system-prompt-manager@0.1.1`

### Fixed
- 修正 prompt manager 內部 hard-coded state enum 造成後續新增 state 必須改 code 的問題

### Removed
- 移除 capability input schema 中的 `state: ["common"]` enum 限制

## Impact
- 後續新增 state 時只需新增對應 prompt 檔案，不需要修改 prompt manager state 清單
- 目前 TalkEngine 固定傳入 `common`，但 prompt manager 不限制 state 只能是 `common`

## Risks & Rollback
- 若 state 命名與檔名規則不一致，會回傳 default prompt 並記 warning；回滾可退回 `system-prompt-manager@0.1.0` 的 single-state 行為
