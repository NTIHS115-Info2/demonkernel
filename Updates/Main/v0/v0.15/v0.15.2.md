## Summary
- 全域 logger 新增 request-scoped 診斷 ring buffer；raw log 改為異常才導出

## Changes
### Added
- 新增 observability 契約（kind/requestId/eventType/outcome）；新增 LOG_STREAM_RAW 強制直寫覆蓋

### Changed
- talk-engine/discord/llm-remote-gateway/conversation-history/pluginsManager 接入摘要+raw 分流；重要節點維持正常落盤

### Fixed
- 修正 streaming 熱路徑完整 payload/content 常態落盤造成延遲與隱私風險；修正 request 成功未清理 raw buffer 的風險

### Removed
- 移除 hot path 常態完整 raw 落盤策略

## Impact
- 降低高頻序列化與 GC 壓力；異常時仍可取得最近 N 筆診斷上下文
