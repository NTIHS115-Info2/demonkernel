## Summary
- 移除 prompt manager 的 hard-coded state 限制

## Changes
### Added
- 新增非 `common` state 讀取對應 prompt 檔案的測試覆蓋

### Changed
- `getSystemPrompt({ state })` 改為依上游傳入 state 尋找 `{state}.system.prompt.md`
- capability input schema 的 `state` 從 `enum: ["common"]` 放寬為一般 string
- plugin README 改為中文，並明確記錄 state 由呼叫端傳入

### Fixed
- 修正 prompt manager 內部定義可用 state 清單造成後續擴充困難與使用誤解的問題

### Removed
- 移除 `SystemPromptState = "common"` 型別與 local strategy 的 unsupported state throw path

## Impact
- 新 state 只需新增對應 prompt 檔案，不需要修改 prompt manager code
- 找不到對應檔案時仍 warn 並回傳 fallback prompt
