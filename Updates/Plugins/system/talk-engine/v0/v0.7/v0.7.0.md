### Changed
- Prompt Composer messages 由 `history + user` 改為 `system prompt + history + user`
- TalkEngine README 與 manifest 更新為 `0.7.0`

### Fixed
- 本版未修正既有 runtime bug

### Removed
- 本版未移除既有功能

## Impact
- 所有 TalkEngine LLM request 會帶有由 prompt manager 提供的 common system prompt
- LLM gateway 維持 message validation / transport 邊界，未新增 prompt 管理責任
